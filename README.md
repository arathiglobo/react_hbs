
# Agent Dashboard (Create React App)

This project contains an Agent Dashboard React implementation using:
- React 18.2.0
- Create React App structure
- React Bootstrap 2.10.4
- react-chartjs-2 + chart.js
- SCSS overrides to match Tailwind palette (indigo-500, green-500, etc.)

How to use:
1. `npm install`
2. `npm start`

This is a focused project that includes:
- src/components/Sidebar.jsx
- src/components/LineChart.jsx
- src/components/BarChart.jsx
- src/pages/AgentDashboard.jsx
- src/App.jsx (router + demo integration)
- src/styles/custom.scss (Bootstrap overrides + utility classes)

You can copy the `src/components` and `src/pages/AgentDashboard.jsx` into your existing project and import `custom.scss` to match the original design.
